# 设备接入试点方案

> 配合《WMS 装车调度与可视化系统 · 决策与设计补充 v3》第 8 节。
> 给出现场设备接入的"试点选仓 → 选型 → 预算 → 工期 → 验收"全流程方案，便于商务与客户决策。
> 价格区间参考国内 2025-2026 年市场行情（含税不含安装），实际以采购询价为准。

---

## 1. 试点目标与原则

### 1.1 目标
- 用最小成本，验证三类核心能力：**车辆识别 + 称重 + 装车进度感知**；
- 跑通"事件驱动"的全链路：从识别 / 称重到调度引擎到大屏与小程序；
- 形成可复制的"装车自动化包"，后续推广到其他仓 / 其他客户。

### 1.2 选点原则
- **业务量足够**：日均装车 ≥ 30 车次，能在 2~4 周内积累足够数据；
- **现场条件好**：有动力电、网络、土建空间，避免过度施工；
- **业务方愿意配合**：现场班组接受度高、领导支持；
- **风险可控**：建议挑钢厂或大型仓储客户而不是危化客户做第一站，化工试点放在第二批。

### 1.3 试点范围（建议）
- **1 个客户、1 个基地、1~2 个代表性仓库**；
- **1 个进出大门** + **1 台地磅** + **2~4 个装车位**；
- 不在试点改造天车 PLC（PLC 试点放化工 / 粮油之外、单独立项，详见 v3 第 3 节）。

## 2. 设备清单与选型

### 2.1 总览（一个试点单位的标准包）

| 序号 | 设备 / 系统 | 数量 | 用途 | 关键指标 |
|-----|-----------|-----|-----|---------|
| 1 | 车牌识别一体机 | 2~4 | 大门进 / 出 / 仓库门 | 识别率 ≥ 99%，200 万像素，宽动态 |
| 2 | LED 闸口诱导屏 | 1~2 | 叫号 / 引导 | P5 全彩、室外亮度 |
| 3 | 道闸（如需） | 1~2 | 大门控制 | 与 LPR / 系统联动 |
| 4 | 地磅集成 | 1 套 | 皮 / 毛重 | 既有地磅改造 + 仪表对接 |
| 5 | 工业 PDA | 4~8 | 班组扫码 / 装车确认 | 安卓 12+，IP65，5G/WiFi |
| 6 | 装车位摄像头 | 4~8 | 视觉进度 / 安全 | 200~400 万像素，POE |
| 7 | 大屏（调度大厅） | 1 套 | 大厅大屏 | 拼接屏 3×2 (P1.86 LED 或 LCD) |
| 8 | 边缘服务器 | 1 台 | device-gateway / 视觉推理 | 8C16T / 64G / GPU 可选 |
| 9 | 工业网络（交换机 / AP） | 若干 | 现场组网 | 千兆 + 工业级 / WiFi 6 |
| 10 | 软件 | 1 套 | 厂商交付（本系统） | 详见主设计文档 |

### 2.2 选型详解

#### 2.2.1 车牌识别一体机
- **推荐品牌**：海康 iDS-TCM 系列、大华 ITC 系列、宇视 IPC2125 系列；
- **识别方式**：相机自带算法识别，也可走边缘服务器二次识别（提高弱光准确率）；
- **关键参数**：宽动态 ≥ 120dB，逆光 / 雨雾抗干扰，支持新能源 8 位车牌；
- **接口**：HTTP / SDK / RTSP；事件以 JSON 推到 device-gateway；
- **冗余**：识别失败自动转人工（小程序 / 门岗补录）。

#### 2.2.2 LED 闸口诱导屏
- **规格**：P5 室外全彩，尺寸约 2m×1m，亮度 ≥ 6000nit；
- **接入**：HTTP API / 串口；展示叫号、目标仓、装车位号、等待时间；
- **品牌**：洲明、利亚德、艾比森均可。

#### 2.2.3 道闸
- **可选**：试点初期可不做联动，识别 + 人工放行更稳；
- **如做联动**：海康 / 大华道闸，与 LPR 一体机厂家配套，避免协议踩坑。

#### 2.2.4 地磅集成
- **现场地磅多为既有设备**，关键是仪表型号（耀华 XK3190、托利多 IND 系列、梅特勒等）；
- **接入方式**：
  - 仪表自带 RS232/485 → 加装协议转换器（Modbus TCP / OPC UA / 自定义）；
  - 仪表自带网口（部分中高端型号）→ 直接对接；
- **二次仪表盒**：建议加装第三方"地磅采集网关"（如研华 ADAM-4571 + 自研驱动），避免改动地磅原系统；
- **数据**：皮重 / 毛重 / 净重 / 时间戳 / 车牌（与 LPR 关联）。

#### 2.2.5 工业 PDA
- **推荐品牌**：富士通 / 优博讯 i6310 / 优博讯 i6200S / 海康；
- **关键参数**：安卓 12+、IP65、扫码引擎（霍尼韦尔 N6603 等）、4G/5G + WiFi 6；
- **使用场景**：行车工 / 地面指挥点击装车开始 / 进度 / 完成；扫码核对货物。

#### 2.2.6 装车位摄像头
- **作用**：
  - 一期：辅助安全与回放，不做 AI；
  - 二期：装车进度视觉识别（吊次计数、装车完成判别）；
- **品牌**：海康 / 大华 / 宇视 POE 半球或筒机；
- **AI 能力**：可在边缘服务器跑（YOLO / 自训模型），本系统不绑定厂家。

#### 2.2.7 调度大厅大屏
- **方案 A**：LCD 拼接屏 3×2 / 4×2（55" / 46"，0.88mm 拼缝）—— 性价比高；
- **方案 B**：小间距 LED P1.86 / P1.53 —— 显示无缝、效果更好、更贵；
- **播放主机**：Windows 工控机 + 多屏拼接卡 / 边缘服务器 + Web 全屏；
- **建议**：调度大厅"足够大"按 6m × 2.5m 起步设计。

#### 2.2.8 边缘服务器
- **配置建议**：CPU 8 核 16 线程、RAM 64GB、SSD 1TB、GPU 可选（视觉 AI 用 RTX 4060 或 A2000）；
- **作用**：
  - device-gateway 现场部署（保障现场断网仍可缓冲事件）；
  - 视觉 AI 推理（如需）；
  - 大屏前端的本地缓存；
- **冗余**：双机热备（或单机 + 数据本地缓冲 + 自动恢复）。

#### 2.2.9 网络
- **有线**：核心交换机（华为 / H3C / 锐捷千兆三层）+ 接入交换机；
- **无线**：工业级 AP（华为 AP6760、Aruba 535）覆盖装车位 + 大门 + 磅房 + 调度大厅；
- **隔离**：设备网 / 业务网 / 视频网三段 VLAN，安全联动。

## 5. 采购与工期

### 5.1 采购周期（按合同生效计）
| 项 | 周期（自然天） |
|----|---------------|
| 车牌识别 / 摄像头（海康大华） | 2 ~ 3 周（现货品） |
| LED 诱导屏 / 大屏 | 4 ~ 6 周（多为定制） |
| 工业 PDA | 2 ~ 4 周 |
| 边缘服务器 | 3 ~ 6 周（看是否标配） |
| 网络设备 | 1 ~ 2 周 |
| 地磅协议网关 / 仪表配件 | 1 ~ 2 周 |

> 整体采购周期 **4 ~ 8 周**取决于大屏是否定制。如果先用现成显示器代大屏，采购最快 **3 周内完成**。

### 5.2 安装与联调（按现场配合到位计）
- 现场勘查 + 方案确认；
- 弱电、网络布线（视客户原状，可能需土建配合）；
- 设备进场安装与上电；
- 设备网关接入，事件打通；
- 与本系统 BFF 联调；
- 大屏内容部署；
- 试运行 + 数据校验；
- 培训与移交。

> 工期总量按"技术阶段 + 风险"评估，不给出绝对天数；建议合同里把各阶段拆成可验收里程碑。

### 5.3 验收里程碑

| 里程碑 | 验收点 |
|-------|------|
| M1 现场就绪 | 网络、电源、安装位 ready |
| M2 设备上线 | 所有硬件上电 + 协议联通（device-gateway 收到心跳与样本事件） |
| M3 业务联通 | 车牌识别触发到仓事件 → 调度引擎反应 → 小程序 / 大屏更新 |
| M4 闭环试跑 | 至少 50 车次完整流程跑通（识别 → 称重 → 装车 → 出门） |
| M5 KPI 验收 | 见下文 |
| M6 移交培训 | 操作手册、应急预案、值班操作培训完成 |

### 5.4 验收 KPI（建议合同写入）

| 指标 | 目标 |
|-----|------|
| 车牌识别率（白天 / 夜间） | ≥ 99% / ≥ 95% |
| 称重事件丢失率 | ≤ 0.1% |
| 事件落库延迟 | ≤ 5s |
| 司机端引导查询响应 | ≤ 2s |
| 调度决策响应 | ≤ 1s |
| 大屏刷新延迟 | ≤ 2s |
| 系统月度可用性 | ≥ 99.5%（试点期）/ ≥ 99.9%（推广期） |
| 试点车次 | ≥ 1000 车次（连续 4 周） |

## 6. 风险与缓解

| 风险 | 缓解 |
|-----|-----|
| 现场弱电 / 土建超期 | 提前现场勘查；改造图纸由客户与设备厂家共同确认；预留 20% 工期缓冲 |
| 地磅仪表型号特殊 / 老旧 | 备一台便携式磅显接口转换器；必要时增加二次显示器 |
| 网络不稳定（厂区电磁干扰） | 边缘服务器本地缓冲；MQTT QoS 1+；自动重传 |
| 车牌识别在冬天 / 夜间衰减 | 加装补光、清洁罩；二次识别（边缘 AI）兜底 |
| 调度大屏审美 / 信息密度争议 | 模板化、可配置；上线前与客户共审至少 2 轮 |
| 现场班组抵触 | 培训 + 试运行期保留人工流程并行；试点验证后再切硬切换 |
| 设备厂家配合度 | 选主流品牌、签 SLA、必要时购买原厂集成服务 |

---

## 7. 后续推广策略

试点验证通过后，按以下顺序推广：

1. **同客户其他仓**：复用配置与 SOP，快速复制；
2. **同行业新客户**：把试点配置打包成"行业起步包"（钢铁版 / 仓储版）；
3. **跨行业（化工 / 粮油 / 水泥）**：在标准包基础上叠加行业插件与专用设备（流量计 / 自动取样 / 危化探测）；
4. **天车 PLC 与自动化深化**：单独立项，进入 L2 → L3 阶段。

## 8. 给客户的清单建议（供商务参考）

- **最简起步包（约 20 万）**：车牌识别 + 地磅集成 + PDA + 边缘服务器 + 现成显示器代大屏；
- **标准试点包（约 35~50 万）**：在最简包基础上加 LED 诱导屏 + 调度大屏（LCD 拼接）+ 装车位摄像头；
- **完整体验包（约 60~75 万）**：标准包 + 道闸联动 + 视觉 AI 服务器 + 工业 AP 全覆盖。

> 三档可作为商务报价梯度，鼓励客户从最简起步包入手降低决策门槛，再按 ROI 升级。
