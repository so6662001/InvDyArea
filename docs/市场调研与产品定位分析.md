# WMS 装车调度与可视化平台 · 市场调研与产品定位分析

> 基于 2025-2026 年公开数据与行业访谈观察整理。
> 数据来源：智研咨询、共研咨询、华经产业研究院、我的钢铁网、宝武 / 宝信公开材料、中冶赛迪官网、找钢网招股文件、东方财富等。
> 价格区间为公开市场行情参考值，具体合同价以实际谈判为准。

## 1. 行业现状（结合目标客户群体）

### 1.1 中国 WMS 市场盘子

| 指标 | 2025 | 2026E |
|-----|------|------|
| 中国 WMS 市场规模 | 61.93 亿元（YoY +14.9%） | 约 70+ 亿元 |
| 行业产值 | 71.01 亿元（YoY +11.9%） | 约 80 亿元 |
| 大中华区制造业 WMS | — | 突破 15 亿元 |

**下游结构**：制造业 20%、零售 16%、电商 15%、医药 15%、其他 34%。

**关键判断**：
- WMS 整体盘子**中速增长（+12~15%）**，离"红海"还有距离，但通用 WMS 同质化严重；
- **行业纵深 + 装车 / 物流段**是当前最大空白；
- **多租户产品化** + **设备 IoT 一体化**是结构性机会。

### 1.2 目标客户群体的产业体量

#### 1.2.1 钢铁行业
- 2026 年中国粗钢产量预计 **9.4 亿吨**（YoY -2.2%），钢材需求 8 亿吨。
- 钢厂集中度：CR10 从 44% → 48%，预计形成 **3-4 家亿吨级龙头**主导格局，但仍有大量**百万吨级中型钢厂**和区域钢厂存在。
- **物流成本占总成本 10~15%**，比发达国家高 3-5 个百分点。
- 钢铁生产基地对外运输量 **43 亿吨/年**，厂内物流量 **80~100 亿吨/年**。
- 数字化升级潜在收益：**吨钢直接物流成本可降 30~50 元、间接 50~80 元**。
- 痛点共识：装车排队压车、调度人工经验、信息孤岛、安全压力。

#### 1.2.2 大型仓储 / 第三方仓储
- 经济下行但**仓储数字化是逆周期的**——客户愈在意效率与单位坪效。
- 痛点：60% 以上仓储企业仍依赖 Excel + 纸单；多业主、多业态、多平台对接复杂；通用 SaaS 无法承接复杂场景；倾向**独立部署 WMS**。
- 钢铁专项仓储（钢贸仓 / 港口堆场）数量众多，国内大型钢贸仓数百家，单仓年装车 5-20 万车次。

#### 1.2.3 钢贸 / 钢铁电商
- 钢铁产业互联网形成两大平台：**找钢网**（2024 交易量约 5000 万吨、交易额约 2000 亿元；胖猫云 ERP 在服客户 2000+；2025 年 3 月港股上市）、**钢银电商**（2019 年结算 3700 万吨）、**欧冶云商**（宝武体系）。
- 电商平台自身已承担"撮合 + 仓配 + 金融"的角色，但**装车段、3D 可视化、司机引导**仍是各家薄弱点。
- 钢贸商总数估计 **10 万家+**，其中**有自建仓 / 长期合作仓的中大型钢贸商约 5000~10000 家**，是潜在 SaaS 客户。

#### 1.2.4 水泥 / 化工 / 粮油（横向扩展行业）
- **水泥**：散装装车自动化已被博乐、丰博、曼沃斯等做了一轮，但多为单点设备方案，缺**多仓多车间统一调度 + 司机端**。
- **化工**：危化品仓储市场被用友畅捷通、伏锂码云、华翕、中慧仓等切分，重在**合规 + 台账 + MSDS**，弱在**装车调度 + 司机引导 + 3D**。化工厂数字化付费意愿强（合规驱动）。
- **粮油**：中储粮+浪潮已建成全球最大物联网粮库（千亿级投入），但商品粮 / 民营粮库仍是空白；装车段普遍仍依赖一卡通 + 人工。

### 1.3 政策与外部驱动
- "工业互联网 + 智能制造"补贴持续；
- 钢铁行业**碳中和 / 超低排放改造**驱动数字化（运输车辆、装车排队均与排放强相关）；
- 危化品安全监管趋严（"十四五"危化品全过程数字化监管要求）；
- 国资 + 大型央企供应商白名单制更明显，民企客户对小厂商更友好。

                              │  · 浪潮（粮库）
                              │

   ◀──────────────────────────┼──────────────────────────▶
                              │

### 2.2 主要竞品逐家拆解

#### 2.2.1 象限 A：行业巨头（重型集成）
| 竞品 | 体量 | 主战场 | 强项 | 弱项 |
|-----|-----|-------|------|------|
| 宝信软件 | 上市，国企 | 宝武 + 大型钢厂 | MES、ERP、整厂智能化、行车调度（炼钢厂铁包、湛江无人鱼雷罐车）；项目周期长但稳 | 项目制 / 价格高 / 周期长（15+ 月）；中型钢厂、钢贸、仓储不接 |
| 中冶赛迪 | 上市，央企 | 中冶系 + 大型钢厂 | 设计 + 软件一体；马钢炼铁智控、配载体系；料场无人化 | 同上；以设计院方式为客户出活 |
| 浪潮 | 上市，国企 | 政府 + 国储粮 | 中储粮智慧粮库（30 亿投入、近千库点） | 钢铁 / 仓储 / 化工渗透弱 |

> **判断**：象限 A 把控特大客户（宝武、河钢、沙钢、中储粮等），但**对中型钢厂、第三方仓储、钢贸、化工、粮油民企吃不动**——价格高、周期长、不灵活。这是我们的主战场缝隙。

#### 2.2.2 象限 B：通用 WMS / SaaS
| 竞品 | 评分（公开） | 主战场 | 强项 | 弱项 |
|-----|-------------|-------|------|------|
| 富勒科技 | 9.5+，市占率约 14.5% | 物流仓配头部 | 复杂仓配 / 波次 / AGV 协同；标杆 1000+ | 单仓 >10 万/年；钢铁装车 / 3D / 司机引导薄弱 |
| 科箭 | 9.3 | 制造 + 医药 | 云原生 + 低代码 + ERP 协同 | 行业纵深一般；3D / 装车段空白 |
| 唯智、汉得、赛意 | 7.1%-6.4% 市占率 | 制造业 | 一体化、ERP 协同 | 装车 / 调度 / 现场 IoT 不强 |
| 通天晓 | 9.6 | 家电、3C、快消 | 高并发、日订单 300 万+ | 钢铁 / 化工不深 |
| SAP EWM / Manhattan / BY | 全球 33% 份额 | 跨国大客户 | 全球标准、合规强 | 价格高、本地化弱、无司机端 |
| 找钢网 / 胖猫云 ERP | 在服 2000+ | 钢贸 SaaS | 钢贸生态贴近、撮合协同 | 装车段 / 厂内 3D / 调度算法不深 |
| 钢银云 | 大体量 | 钢贸 | 财金一体 | 同上 |

> **判断**：通用 WMS 与钢贸 SaaS **看似行业相邻，但都没把"装车调度 + 司机端 + 3D 可视化"做成产品**。这是个**水平市场未覆盖的纵深需求**——空间在这里。

#### 2.2.3 象限 D：专项设备 / 可视化
| 竞品 | 主战场 | 强项 | 弱项 |
|-----|-------|------|------|
| 图扑、灵图 | 数字孪生 3D | 美术 / 渲染 / 大屏 | 业务系统弱，需配合其他厂商 |
| 瓦特曼 WATT | 无人天车 / 数字料场 | 天车自动化 + 视觉 | 装车段 / 司机端弱 |
| 博乐、丰博、曼沃斯 | 水泥散装装车 | 单点设备 + 计量 | 多仓调度 / 司机引导弱 |
| 极智嘉、快仓、海柔、旷视 | AGV / AMR + WMS | 机器人 + 软件 | 重资产、平面仓装车不是其主场 |
| 用友畅捷通、伏锂码云、华翕、中慧仓、匡腾 | 危化 WMS | 合规 / 台账 / MSDS | 装车 / 3D / 司机引导弱 |

> **判断**：象限 D 是"**点状解决方案**"，谁来做"调度 + 引导 + 可视化 + 统计"的串联层，谁就拿到行业平台位。

### 2.3 竞品小结：当前市场缺什么

把上面拆开看，会发现一个清晰缝隙：

| 能力 | 行业巨头 | 通用 WMS | 数字孪生 | 专项设备 | 我们 |
|-----|---------|---------|---------|---------|-----|
| 装车调度算法（自动化） | ★★★（仅特大客户） | ★ | ✕ | ★（单点） | ★★★ |
| 司机自助端（小程序） | ✕ | ✕ | ✕ | ✕ | ★★★ |
| 仓库 3D 可视化 | ★★（项目化） | ✕ | ★★★（弱业务） | ✕ | ★★★（业务驱动） |
| 厂区路径规划 | ★★ | ✕ | ★ | ✕ | ★★★ |
| 多行业模板 | ✕ | ★（电商 / 制造） | ✕ | ✕（单一） | ★★★（6 个） |
| 多租户 SaaS + 私有部署 | ✕（项目制） | ★ | ✕ | ✕ | ★★★ |
| 设备接入（车牌 / 磅 / PLC / IoT） | ★★ | ✕ | ★ | ★ | ★★★（device-gateway） |
| 中小客户性价比 | ✕ | ★★ | ★ | ★★ | ★★★ |

> **核心缝隙**：把"**装车调度引擎 + 司机小程序 + 3D 可视化 + 设备 IoT**"端到端串起来，做成**多行业、多租户、双形态**的产品，目前**市场上没有同时具备这五个 × 三个属性的玩家**。

## 3. 我们的优劣势（SWOT）

### 3.1 优势 Strengths
1. **业务定位差异化清晰**：聚焦"装车 + 司机 + 调度 + 可视化"端到端段，避开重型 MES / EWM 红海。
2. **现有 WMS / ERP 基础**：作为已有产品的延伸演进，不是从零冷启动；客户教育成本低。
3. **架构超前**：从一开始就走"多租户 + 多形态 + 行业插件 + 设备抽象"，而不是在老架构上打补丁。
4. **研发实战能力**：Java + Vue + Three.js + 边缘 IoT 都在团队能力圈内，无技术鸿沟。
5. **司机微信小程序**：被国资派 / 数字孪生派系统性忽视的"最后一公里"，是用户口碑传播的关键。
6. **价格灵活**：相对宝信 / 中冶 / 富勒 / SAP，我们能给出**显著低且仍盈利**的定价。

### 3.2 劣势 Weaknesses
1. **品牌与标杆案例缺**：尚未形成行业可见度，进国资白名单门槛高。
2. **行业 know-how 积累不均**：钢铁有底子；化工 / 粮油 / 水泥需要靠 1-2 个标杆客户补齐。
3. **资金与人力规模**：相对宝信、富勒、SAP 中国体量小，难以同时大客户战和广泛销售。
4. **服务半径有限**：私有部署需要本地实施 + 现场设备调试，初期跨省服务成本高。
5. **三维 / 算法专业人才招聘门槛**：Three.js 和 OR-Tools 等技能不在 Java 主流招聘池。
6. **设备生态依赖**：地磅、车牌、PLC 厂家众多，设备适配是长期工程。

### 3.3 机会 Opportunities
1. **CR10 提升中型钢厂洗牌**：被兼并 / 被压利润的中型钢厂迫切需要降本数字化。
2. **钢铁 / 化工碳排监管收紧**：装车调度直接影响排放、车辆怠速、空驶率，政策推动数字化付费意愿。
3. **大型仓储独立部署需求强**：他们对私有部署 + 数据自有 + 定制化的偏好与我们的双形态正好匹配。
4. **找钢网 / 钢银 / 欧冶可做生态**：他们自己不做装车段，可以与他们的 SaaS 互补合作（嫁接到他们 2000+ 客户上）。
5. **危化合规驱动**：新一轮危化品全过程数字化监管，化工厂被迫升级，是行业插件的好切入。
6. **国产替代**：SAP / Oracle / Manhattan 高价 + 缓慢响应，国产替代窗口长期存在。

### 3.4 威胁 Threats
1. **巨头降维打击**：富勒、宝信若意识到此缝隙，资源 / 渠道远超我们。
2. **找钢网 / 钢银向上吃**：钢贸 SaaS 平台向"装车段"扩展是天然方向。
3. **数字孪生厂商向下吃**：图扑、灵图等若做业务系统化，会切走 3D 可视化的市场印象。
4. **客户预算紧张**：钢铁行业利润下行（产量降、需求降），数字化预算收紧。
5. **自研陷阱**：大客户倾向"自建"或"找设计院定制"，绕开标准产品。
6. **设备厂家自闭环**：海康 / 大华 / 宇视等设备厂家在做自家"+AIoT 平台"，可能挤压第三方平台空间。

## 4. 平台未来市场空间（TAM / SAM / SOM）

> 自下而上估算，结合 WMS 大盘 + 行业体量两路交叉验证。

### 4.1 TAM（潜在市场总量）

把范围限定为**"流程制造 + 第三方仓储 + 钢贸"四类客户中和'装车调度 + 司机引导 + 3D 可视化 + 装车统计'相关的软件+服务支出**。

| 客户群 | 客户量级 | 单客年化 IT 支出（与本平台相关部分） | 年支出量级 |
|-------|---------|--------------------------------|-----------|
| 钢铁企业（含中型 + 区域） | 约 500 家 | 30~150 万 | 1.5~7.5 亿 |
| 大型 / 第三方仓储 | 约 3000 家（含钢贸仓 / 港堆场 / 工业品仓） | 10~80 万 | 3~24 亿 |
| 钢贸（中大型有自建仓 / 长合仓） | 约 5000~10000 家 | 5~30 万 | 2.5~30 亿 |
| 水泥 | 约 1000 家（粉磨站 + 立窑厂） | 10~80 万 | 1~8 亿 |
| 化工（含危化 + 非危化） | 约 5000 家具仓客户 | 20~150 万（合规驱动） | 10~75 亿 |
| 粮油 | 商品粮 + 民营粮库 约 3000 家 | 10~60 万 | 3~18 亿 |

**TAM 区间：约 21~163 亿元/年**（取中位数 ≈ **70~80 亿元/年**）。

> 与 WMS 大盘（2026 约 70+ 亿元）规模相当，相互交叉验证 TAM 在**同一数量级**。注意 TAM 不只是 WMS，还包含上游 IoT、设备集成、行业插件、服务费。

### 4.2 SAM（可触达市场）

考虑**双形态可交付**、**客户能接受民营品牌**、**设备试点支持范围**等约束，SAM 估算：

| 阶段 | 可触达客户 | 估算客户数 | 年化贡献 |
|-----|-----------|----------|---------|
| 近期 | 中型钢厂 + 第三方钢铁仓 + 区域钢贸 + 民营水泥 | 约 1500 家 | 12~25 亿元/年 |
| 中期 | 加 化工（非危化为主）+ 商品粮 | 约 3500 家 | 25~50 亿元/年 |
| 远期 | 加 危化 + 国储 + 跨界（建材 / 医药冷链） | 约 8000 家 | 50~100 亿元/年 |

**SAM ≈ 25~50 亿元/年**（中期判断），是个能容纳**多家亿级营收公司**的市场。

### 4.3 SOM（可获得市场）

中期目标：在 SAM 中做到 **5~10% 渗透**，对应：
- **签约客户 200~400 家**；
- **年化合同额（ARR）2.5~5 亿元**；
- 单客均价 80~150 万元（含软件 + 服务 + 行业插件）。

支撑这一目标需要：5~8 个标杆案例、3~5 套行业模板、2~3 个区域实施合作伙伴、SaaS 与私有部署双产品线。

### 4.4 增速判断
- WMS 大盘 +12~15% / 年；
- 钢铁数字化（结合宝武智慧物流、中冶料场、找钢网 IPO 成功背书）正进入**加速复制期**；
- 化工监管驱动属强制需求，复合增速预计 **15~20%**；
- 综合：**目标市场 5 年内有 1.5~2 倍空间**，足以容纳新进者。

> **结论**：市场空间足够大，**有空间做产品级玩家**，不是只做项目集成商。

## 5. 产品定位（既然有空间）

### 5.1 一句话定位

> **"流程制造与大宗仓储行业的装车调度与可视化中台"——一份代码，覆盖钢铁、仓储、钢贸、水泥、化工、粮油六大行业；SaaS 与私有部署双形态；从订单到司机出门一站打通。**

### 5.2 三层定位

**产品层**：装车段端到端产品平台（不是"又一个 WMS"，也不是"又一套大屏"）。
**客户层**：以**中型钢厂 + 第三方仓储 + 区域钢贸**为基本盘，逐步向水泥 / 化工 / 粮油扩展。
**生态层**：与 ERP / WMS / 钢铁电商平台**互补共存**，做装车段的"插件式中台"。

### 5.3 与主流玩家的差异化定位语

| vs | 我们的差异 |
|-----|-----------|
| vs 宝信 / 中冶赛迪 | 我们**轻、快、产品化**，能服务他们不接的中型客户 |
| vs 富勒 / 科箭 / 通天晓 | 我们**做装车段纵深**，他们做仓内通用 WMS，互补不冲突 |
| vs SAP / Manhattan | 我们**本地化 + 一份价 + 多行业模板** |
| vs 图扑 / 灵图 | 我们**业务驱动 3D**，不是渲染驱动；3D 后面跑的是真实调度 |
| vs 瓦特曼 / 博乐 / 丰博 | 我们**软件平台 + 设备开放**，不绑定单一硬件方案 |
| vs 找钢网 / 钢银云 | 我们**做他们没做的厂内 + 装车段**，可生态合作 |

### 5.4 价值主张（对客户讲）
- **司机不再问路**：车牌或电话一刷，立体图 + 路径直达库位。
- **调度不再排队**：自动化派单 + ETA 预估，把车均在厂时长砍掉 30%+。
- **数据不再孤岛**：仓库、班组、产品、客户多维统计，绩效一目了然。
- **上线不再漫长**：SaaS 一周可用、私有部署月级交付，远低于宝信 / SAP。
- **行业不再硬套**：钢铁、仓储、钢贸、水泥、化工、粮油一份系统，各自有插件。

### 5.5 产品边界（不做什么）
明确**不与谁正面冲撞**，是定位成功的关键：
- **不重做 ERP**：不进订单、合同、财务、税务。
- **不替代 WMS 主帐**：库位、批次、库存帐继续由现有 WMS 主导。
- **不卖硬件**：设备由生态伙伴供应，我们只接入。
- **不做立体仓机器人**：与极智嘉 / 海柔 / 快仓互补，不重复造轮子。
- **不做 MES**：不进炼钢、轧钢、烧结的工艺管控。
- **不做撮合**：不与找钢网 / 钢银 / 欧冶在交易撮合上竞争。

### 5.6 行业进入顺序（产品矩阵节奏）

```
基础平台（多租户 + 装车任务 + 司机端 + 3D + 调度）
   ├─ ① 中型钢厂 + 钢铁仓                ← 起家盘
   ├─ ② 大型第三方仓储 + 港堆场           ← 横向扩张
   ├─ ③ 区域钢贸（与找钢/钢银生态合作）   ← 流量复制
   ├─ ④ 民营水泥 / 粉磨站                ← 跨行业 1
   ├─ ⑤ 非危化化工 + 国储粮              ← 跨行业 2
   └─ ⑥ 危化 + 跨界扩展                  ← 远期
```

## 6. 衔接前轮：价格策略与落地打法（精简版）

> 完整方案见前几轮设计文档，本节作为闭环衔接。

### 6.1 价格策略（建议）
- **梯度产品包**：起步包（约 20 万）/ 标准包（35-50 万）/ 旗舰包（60-75 万），含设备配套。
- **软件计价模型**：按"租户 × 仓库数 × 装车位数 × 模块"，订阅 + 永久双模并存（SaaS 走订阅，私有走永久 + 年维护 18~22%）。
- **行业插件单售**：化工 / 粮油 / 水泥单独 license，毛利更高（合规驱动溢价）。
- **PoC 试点首单优惠**：首单友情价 + 案例授权，换"行业首个标杆"。
- **生态分润**：与找钢 / 钢银 / 设备厂家 / 区域代理设清晰返点（10~25%）。

### 6.2 市场落地打法（精简）
1. **拿下 1 个中型钢厂标杆**（产能 200~500 万吨级、民营、决策快）→ 出案例白皮书 + 视频 demo；
2. **同行业横向复制**（区域钢厂 + 钢铁仓）→ 走"行业首发包"；
3. **生态合作**：与找钢网 / 钢银云 / 设备厂家做转介绍 + 联合方案；
4. **行业插件孵化**：在化工 / 水泥 / 粮油各拿 1 个标杆，用插件方式立客户；
5. **品牌动作**：白皮书、ROI 计算器、行业大会发声、3D Demo 直播；
6. **渠道双轨**：原厂直营（大客户）+ 区域代理（中小客户 + 实施服务）；
7. **私有部署售后**：远程接入 SLA + 年度升级费 + 免费迭代 N 个版本，控住口碑。

## 7. 结论

1. **市场盘子有**：WMS 大盘 70+ 亿、目标 SAM 中期 25~50 亿，足够容纳新进者。
2. **缝隙清晰**：装车调度 + 司机端 + 3D + 多行业 + 双形态，**目前没有同时具备这套属性的玩家**。
3. **巨头不会下沉、专项不会上来**：宝信 / 中冶 / SAP 不接中型客户；图扑 / 博乐 / 用友只做单点。我们恰好坐在缝隙里。
4. **风险可控**：威胁主要来自富勒 / 找钢若发力，但他们短期重心不在这里；自身风险在于标杆案例、行业插件积累、设备生态。
5. **建议立项**：以"流程制造与大宗仓储装车调度可视化中台"为产品名，按"基础平台→钢铁/仓储→钢贸→水泥/化工/粮油"节奏推进，3 年内做到 ARR 1~2 亿 / 客户 100+，跻身行业第二阵营。

> 下一步建议先与销售 / 售前一起做 **3-5 个目标客户的真实预算与决策链摸底**，再据此校准价格曲线与市场节奏。
